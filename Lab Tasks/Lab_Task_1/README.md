# Maharishi Store Clone

A modern, responsive e-commerce website clone of the Maharishi Store, built with HTML, CSS, and Bootstrap 5.3.2. This project demonstrates advanced web development techniques including mega menus, carousels, grid layouts, and responsive design.

## Features

### 1. Navigation
- **Mega Menu System**
  - Horizontal main categories with vertical subcategories
  - Smooth hover transitions
  - Responsive grid layout for subcategories
  - Clean typography and spacing

- **Search Functionality**
  - Toggle search bar with smooth animation
  - Clean, minimal search interface
  - Responsive design

### 2. Hero Section
- **Bootstrap Carousel**
  - Full-screen image slider
  - Auto-play functionality
  - Custom navigation arrows
  - Overlay text with call-to-action buttons
  - Smooth transitions between slides

### 3. Product Grid
- **Responsive Grid Layout**
  - Two-column and three-column layouts
  - Full-width showcase images
  - Image hover effects
  - Overlay text and buttons

### 4. Journal Section
- **Grid-based Journal Display**
  - 3x2 grid layout for articles
  - Square aspect ratio images
  - Hover effects with elevation
  - Article titles and descriptions
  - "Read more" links with animated underlines

### 5. About Section
- **Full-width Design**
  - Clean typography
  - Brand story presentation
  - Responsive layout
  - Call-to-action button

### 6. Footer
- **Multi-column Layout**
  - Quick links section
  - Contact information
  - About section
  - Copyright information
  - Responsive grid system

### 7. Modal System
- **Checkout Modal**
  - Form validation
  - Email validation (Gmail)
  - Responsive design
  - Error handling
  - Smooth animations

## Technical Features

### 1. Responsive Design
- Mobile-first approach
- Breakpoints:
  - Desktop: 1200px+
  - Tablet: 992px - 1199px
  - Mobile: < 768px

### 2. CSS Architecture
- BEM-like naming convention
- Modular CSS structure
- Custom properties for consistency
- Flexbox and Grid layouts
- Hardware-accelerated animations

### 3. Performance Optimizations
- Lazy loading images
- Optimized asset loading
- Minimal JavaScript usage
- Efficient CSS selectors

### 4. Browser Compatibility
- Modern browser support
- Fallback styles where needed
- Cross-browser testing

## Dependencies

- Bootstrap 5.3.2
- Custom font: Univers
- Modern browser with CSS Grid support

## Setup Instructions

1. Clone the repository
2. Ensure all image assets are in the root directory
3. Open `index.html` in a modern web browser
